### 2) 🎓 `2_courses/`

**Course notes or content extracted from courses.**  
Includes:

- 🗒️ Notes organized by module/topic

### 3) 🛝 `3_playground/`

**A playground: a set of projects to practice.**

- 🧪 Experiments and prototypes

- 🚀 Challenges and practice to solidify learning
